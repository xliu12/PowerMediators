# R scripts for Round-2 simulation and illustration

These R scripts were used in the revision of *Familywise Type I Error Rates and Statistical Power in Causal Mediation Analysis with Multiple Mediators* (Round-2). They used a previous version of the R package, PowerMediators version 0.1.0. Version 0.2.0 of the package adds Holm's procedure to `runPower()` and `cal.sample_size()` and changes no other computation. 
The Round-1 scripts `simulation.R` and `example.R` are at the root of this repository and are unchanged.
